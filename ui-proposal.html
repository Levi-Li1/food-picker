当前 UI 诊断报告

诊断
  • 1
    视觉层级偏平 首页 & 周页的卡片缺少层次感，所有元素都在同一个视觉平面上。添加阴影、渐变、微动效可以拉开层。
  • 2
    缺乏交互动效 卡片悬停、按钮点击、页面过渡均无动效反馈，让人觉得"死板"。微交互动效可以大幅提升使用愉悦感。
  • 3
    色彩系统未充分表达学科特性 蓝色(数学)、绿色(英语)、红色(语文)、橙色(物理) 的好方向可以保留，但需要更多层级：浅色背景、渐变色标题、彩色标签体系。
  • 4
    缺少深色模式 学生可能在晚上/暗光环境下学习，没有深色模式对眼睛不太友好。
  • 5
    首页英雄区略显单薄 进度条、统计数据的展示方式可以更醒目、更有激励感。学生需要看到进度才能保持动力。
  • 6
    单词卡片 & 题目区域可交互性不足 词汇表和练习题目前是静态展示，增加悬停高亮、点击反馈、平滑动画可以让学习过程更沉浸。

📖 数学 · 有理数与实数

讲（20min）

正负数表示相反意义 → 数轴直观表示数的大小 → 相反数(和为0) → 绝对值(≥0，到原点距离) → 科学记数法(a×10ⁿ) → 实数=有理数+无理数

A组·基础练

1. |-8|的值是？
|-8| = 8（绝对值表示到原点的距离，-8到原点的距离为8）
2. 9的平方根是？
9的平方根是 ±3（正数有两个平方根，互为相反数）
a + (-a) = 0
互为相反数的两个数和为零

方法总结

方法：数轴记忆法：把数画在数轴上，右边>左边。绝对值=到原点的距离。注意0的相反数和绝对值都是0。

当前项目使用了 23 种不同 emoji 作为功能图标（📖🔤📜📝🎯💡✔🧪🏛...等），以及 31 个重复的内联 SVG 播放按钮。以下是优化方案。

📖 📔 📚 ☀ 🔤 📋 📜 📝 🎯 ❗ 💡 ✔ 🧪 🏛 ✓ 📐 🧠 📅 🎵 🎨 🏠 💪 🔗
每个单词卡片旁还有 31 个重复的内联 SVG 播放按钮（▶ 三角形），用于 TTS 发音。
✅ 方案A · 标准化 emoji
保持 emoji，但统一定义 CSS 样式
• 给所有图标 emoji 加统一字号和间距
• 用 font-size 控制图标大小
• 用 filter: drop-shadow 加微阴影
• 播放按钮抽成 SVG <use> 复用
⏱ 无额外依赖 · ⚡ 最快实施 · ⚠️ 跨平台不一致
⭐ 方案B · 内联 SVG 图标系统
自定义 SVG 图标集 + <use> 复用
• 在 HTML 顶部定义 SVG sprites
• 15 个定制图标覆盖所有场景
• 可着色（支持 currentColor）
• 可动画（悬停旋转/缩放）
• 播放按钮只需写一次 <use>
✅ 一致性最佳 · ✅ 可离线 · ⚠️ 需写 SVG 定义
🎯 方案C · Lucide Icons CDN
轻量开源图标库（推荐）
• 引入 CDN：lucide.dev
• 1000+ 高质量 SVG 图标
• 24x24 统一尺寸，支持 currentColor
• 树摇优化，只加载用到的
• 类似 Feather Icons 的极简风格
✅ 最丰富的选择 · ⚠️ 需联网 · ⚠️ 额外 12KB

优化改进清单 · 新增图标专项

Summary

✨ 1. 微交互动效系统

为所有交互元素添加 transition 动效：

  • 卡片悬停 → 上浮 + 阴影加深
  • 按钮点击 → 颜色平滑过渡
  • 链接悬停 → 背景色变化
  • 答案展开 → slideDown 动画

🌈 2. 深色模式

通过 CSS 变量 + data-theme 属性实现：

  • 纯 CSS 方案，无 JS 依赖
  • 所有卡片背景变 dark gray
  • 文字颜色浅色化
  • 边框降低对比度
  • 可加 localStorage 记忆偏好

📐 3. 色彩体系层级化

在现有的四色基础上增加浅色变体：

  • --blue-light 用于背景填充
  • 主色用于文字/边框/图标
  • 渐变色用于头部条
  • 彩色小圆点标识学科

📊 4. Hero 激励升级

首页顶部大改版：

  • 渐变背景+径向光晕
  • 3个分离统计指标
  • 带脉冲动画的进度条
  • 可扩展连击天数/倒计时

🔤 5. 导航条毛玻璃效果

周导航 backdrop-filter: blur()：

  • 毛玻璃半透明背景
  • 活跃周高亮蓝色
  • sticky 固定在顶部
  • 深色模式自动适配

🔘 6. 周卡片视觉升级

首页周卡片大改版：

  • 彩色学科标签 dots
  • 完成状态徽章化

📝 7. 答案按钮毛玻璃化

  • pill 形状圆角
