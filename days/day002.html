📖 数学 · 有理数与实数

讲（20min）

第一步：认识负数

在日常生活中，我们用"+"表示零上、收入、上升；用"−"表示零下、支出、下降。像−3、−0.5、−100这样的数叫负数。正数（如+3）和负数（如−3）的实际意义相反。

0既不是正数也不是负数，它是正数和负数的分界点。

第二步：数轴——把数"画”出来

画一条直线，在直线上取一个点表示0（原点），规定向右为正方向，再取适当的长度作为单位长度——这就是数轴。数轴上，越往右的数越大。

例：在数轴上标出 −3、0、2。−3在原点左边3个单位，2在原点右边2个单位。显然 2 > 0 > −3。

第三步：相反数——关于原点对称

只有符号不同的两个数互为相反数。3和−3互为相反数，它们的和是0。0的相反数还是0。在数轴上，互为相反数的两个点关于原点对称。

口诀：a + (−a) = 0

第四步：绝对值——到原点的距离

数轴上表示一个数的点到原点的距离叫做这个数的绝对值，记作|a|。绝对值永远 ≥ 0（非负）。

例：|−8| = 8（−8到原点的距离是8）；|5| = 5。

一个重要结论：两个负数比大小——绝对值大的反而小。如 |−3| = 3, |−5| = 5，3 < 5，所以 −3 > −5。

第五步：科学记数法

把一个大于10的数写成 a × 10ⁿ 的形式（1 ≤ a < 10，n为正整数），叫做科学记数法。

例：56000000 = 5.6 × 10⁷。步骤：①小数点左移到第一个非零数字后 → 得到a = 5.6；②数一下移了多少位 → n = 7。

第六步：无理数与实数

无限不循环小数叫做无理数，如π = 3.1415926...、√2 = 1.41421356...。有理数+无理数 = 实数。所有能在数轴上找到对应点的数都是实数。

小结

正负数表示相反意义 → 数轴直观表示数的大小 → 相反数(和为0) → 绝对值(≥0，到原点距离) → 科学记数法(a×10ⁿ) → 实数=有理数+无理数

🔤 英语 · 课标词汇1600词

讲（20min）

📖 导入：为什么词汇是英语的根基？

如果把英语学习比作建房子，词汇就是砖块。语法是框架，词汇是填充。中考英语试卷中，每道题都在考查词汇的掌握程度：阅读理解需要认识单词，完形填空需要辨析词义，写作需要准确拼写和搭配。没有足够的词汇量，一切技巧都是空中楼阁。

第一步：课标要求的1600词

教育部规定初中毕业生需要掌握约1600个核心词汇（含小学阶段学的约400词，初中新增约1200词）。但这1600词不是孤立地"背"——中考考查的是四维能力：

① 会读：能根据音标准确发音（听力+口语考试直接考查）
② 会写：拼写正确，尤其是不规则变化的过去式、比较级等
③ 会用：知道词性（动词/名词/形容词等）和常见搭配（be interested in, look forward to等）
④ 知义：理解中文意思，尤其是一词多义——比如"run"既有"跑步"也有"管理(run a company)"的意思

第二步：核心800词——完形和阅读的高频词

1600词中有约800个高频词，在历年中考中反复出现。这些词要做到"条件反射"——看到立刻知道意思，听到立刻能拼写。比如：important/education/different/beautiful/interesting等。剩下800个扩展词做到阅读中能结合上下文猜出意思即可。

第三步：背单词四步法（每天坚持）

第1步：听标准发音（跟读2遍）
第2步：写三遍（边写边读发音）
第3步：造一个简单句（把单词放在语境中）
第4步：第二天复习前一天的词（反复对抗遗忘曲线）

举例：学习 "effort"（努力）
听 /ˈefərt/ → 写 effort, effort, effort → 造句 I put effort into my homework. → 第二天默写

⚠ 常见错误

① 只背意思不背词性 → 写作中容易用错（如用happy修饰动词）
② 只背单词不背搭配 → 完形填空中be interested in/of/for选不出
③ 背了就忘不复习 → 根据遗忘曲线，24小时后记得不到30%

📋 小结

1600课标词→核心800高频→四维能力(读/写/用/义)→四步法背+每日复习。词汇量决定英语成绩的上限！

C组·中考真题

1.【2024·成都中考】用所给词的适当形式填空。My father is a great ________ (invent). He has many patents.
【答案】inventor 【解析】冠词a后面需要可数名词单数。invent是动词"发明"，名词形式inventor"发明家"。句意：我父亲是一位伟大的发明家。故填inventor。
2.【2024·广州中考】The ________ (pollute) of the river is very serious. We must take action to stop it.
【答案】pollution 【解析】定冠词the后面需要名词形式。pollute是动词"污染"，其名词形式为pollution。句意：这条河的污染很严重。故填pollution。

📖 语文 · 字音字形

讲（20min）

一、多音字辨析

中考常考多音字约100个。方法：据义定音——根据词义判断读音。如'曾'读céng(曾经)和zēng(曾祖)。

二、形声字

形旁表义（如氵=水、扌=手、忄=心），声旁表音（如'青'在清/晴/情/请中表音）。但注意有些声旁已不准（如江gōng→jiāng），不能完全凭声旁猜测。

三、易错字

常混字要成对记：躁(急躁/足字旁)vs燥(干燥/火字旁)、侯(王侯)vs候(时候)。推荐每天积累2组对比。

🧪 化学 · 物理变化与化学变化 （初三预习）

讲（20min）

判断唯一标准：是否有新物质生成

物理变化：无新物质（水结冰/铁拉成丝/石蜡熔化。只是状态或形状改变）
化学变化：有新物质（蜡烛燃烧/铁生锈/食物腐败/呼吸作用）
⚠化学变化常伴随发光/放热/变色/产生气体/沉淀，但有这些现象不一定是化学变化（灯泡发光是物理变化！）

A组·基础练

1.下列变化中属于化学变化的是（ ） A. 水结冰 B. 铁生锈 C. 玻璃破碎 D. 酒精挥发
B（铁生锈有新物质Fe₂O₃生成。A水结冰是状态变化，C是形状变化，D是汽化）
2.判断：蜡烛燃烧是化学变化，蜡烛熔化是物理变化。
正确。燃烧产生新物质（CO₂和H₂O），熔化只是状态变化
3.下列过程中发生物理变化的是（ ） A. 食物腐败 B. 光合作用 C. 干冰升华 D. 钢铁生锈
C（干冰升华是固态直接变气态，物态变化）。ABD都有新物质生成
4.判断：有发光放热现象的变化一定是化学变化。
错误。灯泡通电发光放热是物理变化（没有新物质生成）
5.物理变化和化学变化的本质区别是什么？
是否有新物质生成。有新物质生成的是化学变化，没有的是物理变化

C组·中考真题

1.【2024·南京中考】下列变化属于化学变化的是（ ） A. 冰雪融化 B. 纸张燃烧 C. 酒精挥发 D. 矿石粉碎
【答案】B 【解析】化学变化是指有新物质生成的变化。A.冰雪融化只是水的状态由固态变为液态，没有新物质生成，属于物理变化；B.纸张燃烧生成了二氧化碳和水等新物质，属于化学变化；C.酒精挥发是酒精由液态变为气态，没有新物质生成，属于物理变化；D.矿石粉碎只是矿石的形状发生了改变，没有新物质生成，属于物理变化。故选B。
2.【2024·广州中考】下列变化中，属于物理变化的是（ ） A. 铁锅生锈 B. 牛奶变质 C. 酒精燃烧 D. 干冰升华
【答案】D 【解析】A.铁锅生锈生成新物质铁锈（Fe₂O₃·xH₂O），属于化学变化；B.牛奶变质是微生物作用产生新物质，属于化学变化；C.酒精燃烧生成CO₂和H₂O，属于化学变化；D.干冰升华是固态CO₂直接变为气态，分子间隔增大，没有新物质生成，属于物理变化。故选D。
3.【2024·河南中考】我国的古代发明及应用所包含的下列物质变化中，不涉及化学变化的是（ ） A. 粮食酿酒 B. 陶瓷烧制 C. 活字印刷 D. 火药爆炸
【答案】C 【解析】A.粮食酿酒是利用酵母菌将淀粉转化为酒精，有新物质生成，属于化学变化；B.陶瓷烧制过程中黏土中的成分发生复杂的化学反应（如脱水、氧化等），有新物质生成，属于化学变化；C.活字印刷只是将字模蘸墨后印到纸上，没有新物质生成，属于物理变化；D.火药爆炸是火药中的可燃物与氧化剂发生剧烈氧化反应，释放大量气体和热量，有新物质生成，属于化学变化。故选C。

方法总结

方法：判断变化三步：看反应前是什么→看反应后变成什么→有没有新物质。有→化学变化，无→物理变化。
