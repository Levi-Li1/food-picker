📖 数学 · 分式与二次根式

讲（20min）

一、分式

定义：形如A/B（B≠0，B中含有字母）的式子叫分式。分式有意义的条件是分母≠0。分式值为0的条件是分子=0且分母≠0。

基本性质：分式的分子分母同乘（或同除）同一个不为0的数或整式，分式的值不变。

运算：加减先通分，乘法分子分母各自乘，除法乘倒数。

分式方程：去分母化为整式方程→求解→必须验根！使分母=0的根是增根，要舍去。

二、二次根式

定义：√a（a≥0）叫二次根式。注意被开方数必须≥0。

性质：√a² = |a|（关键！不是a）例：√(−3)² = |−3| = 3

运算法则：√a×√b = √(ab)（a≥0,b≥0）；√a÷√b = √(a÷b)（a≥0,b>0）

最简二次根式要求：①被开方数不含能开得尽的因数②分母不含根号

例：√12 = √(4×3) = 2√3； 1/√2 = √2/2（分母有理化）

同类二次根式：化简后被开方数相同的几个二次根式可以合并（类似合并同类项）。

√8+√18 = 2√2+3√2 = 5√2

小结

分式：分母≠0（有意义），值=0需分子0且分母≠0，方程必验根。二次根式：被开方数≥0，√a²=|a|，化简→合并。

A组·基础练

1.当x取何值时分式(x-1)/(x+2)有意义？
分母x+2≠0，即x≠-2（分式有意义的条件：分母≠0）
2.解分式方程1/(x-1)+1=3/(x-1)
两边乘(x-1)：1+(x-1)=3 → x=3，检验x=3时分母x-1=2≠0，所以x=3是解
3.化简√12
√12 = √(4×3) = 2√3（将根号内能开方的因数开出）
4.分母有理化1/√2
1/√2 = √2/2（分母有理化：分子分母同乘√2）
5.计算√8+√18
√8+√18 = 2√2+3√2 = 5√2（先化简再合并同类根式）

C组·中考真题

1.【2024·广州中考】分式方程 1/(x-1) = 2/x 的解是（ ） A. x=1 B. x=2 C. x=3 D. x=-2
【答案】B 【解析】1/(x-1)=2/x → 两边同乘x(x-1)得 x=2(x-1) → x=2x-2 → x=2。经检验x=2时分母不为0，是原分式方程的解。故选B。 【易错】分式方程一定要验根！
2.【2024·长沙中考】下列二次根式中，是最简二次根式的是（ ） A. √4 B. √8 C. √10 D. √12
【答案】C 【解析】最简二次根式必须满足：①被开方数不含开得尽的因数或因式；②被开方数不含分母。A.√4=2，可开方；B.√8=2√2，含开得尽的因数4；C.√10不能化简，是最简二次根式；D.√12=2√3，含开得尽的因数4。故选C。

方法总结

方法：分母有理化口诀：上下同乘根号，分母不含根号。分式方程必验根！

🔤 英语 · 构词法

讲（20min）

📖 导入：英语单词不是乱造的

英语单词的构成有规律可循，掌握构词法可以帮助你举一反三——学一个词就等于学了一串词。

三大构词法

① 派生法（前缀+后缀）：在词根上加前缀或后缀变成新词
前缀改变词义但不改变词性：un-(不)/dis-(不)/re-(重新)/pre-(预)
例：unhappy(不开心)/ disagree(不同意)/ rewrite(重写)
后缀改变词性但不改变核心意思：
名词后缀：-tion/-ment/-ness
形容词后缀：-ful/-less/-y/-able
副词后缀：-ly
例：care→careful(形)→carefully(副)→careless(反义词形容词)

② 合成法：两个独立的词合在一起形成新词
class+room=classroom(教室) / black+board=blackboard(黑板)
foot+ball=football(足球) / sun+flower=sunflower(向日葵)
note+book=notebook(笔记本) / every+one=everyone(每个人)

③ 转化法：一个词从一种词性转换成另一种
名词→动词：water(水→浇水) / hand(手→递) / email(电子邮件→发邮件)
形容词→动词：clean(干净的→打扫) / slow(慢的→减速)

📋 小结

派生(前缀改意思/后缀改词性) + 合成(两个词合一个) + 转化(不改变词形)。记住常见的前缀(un/dis/re)和后缀(-tion/-ful/-ly)。

A组·基础练

1.词性转换：care → ________ (adj.仔细的) → ________ (adv.仔细地) → ________ (adj.粗心的)
careful → carefully → careless（-ful形容词后缀，-ly副词后缀，-less否定形容词后缀）
2.词性转换：possible → ________ (adj.不可能的)
impossible（前缀im-加在p开头的词前表否定=不可能）
3.词性转换：nation → ________ (adj.国家的) → ________ (adj.国际的)
national → international（-al形容词后缀，inter-前缀=在...之间）
4.词性转换：friend → ________ (adj.友好的) → ________ (n.友谊)
friendly → friendship（-ly变形容词，-ship名词后缀表关系/状态）
5.词性转换：agree → ________ (v.不同意) → ________ (n.协议)
disagree → agreement（dis-否定前缀，-ment名词后缀）

C组·中考真题

1.【2024·长沙中考】He is a famous ________ (science). He won the Nobel Prize last year.
【答案】scientist 【解析】冠词a后面需要可数名词单数。science是名词"科学"，其指人的名词为scientist"科学家"。句意：他是一位著名的科学家。故填scientist。
2.【2024·苏州中考】The weather is ________ (please) today. Let's go for a picnic.
【答案】pleasant 【解析】系动词is后面接形容词作表语。please是动词/感叹词，其形容词pleasant意为"令人愉快的"。句意：今天天气宜人。故填pleasant。

方法总结

方法：词性转换口诀：前缀改意思不改词性(un/dis/re)，后缀改词性不改变核心意思(-tion名词/-ful形/-ly副/-er人)。

📖 语文 · 字音字形

讲（20min）

一、多音字辨析

中考常考多音字约100个。方法：据义定音——根据词义判断读音。如'曾'读céng(曾经)和zēng(曾祖)。

二、形声字

形旁表义（如氵=水、扌=手、忄=心），声旁表音（如'青'在清/晴/情/请中表音）。但注意有些声旁已不准（如江gōng→jiāng），不能完全凭声旁猜测。

三、易错字

常混字要成对记：躁(急躁/足字旁)vs燥(干燥/火字旁)、侯(王侯)vs候(时候)。推荐每天积累2组对比。

🧪 化学 · 空气与氧气 （初三预习）

讲（20min）

📖 导入：看不见的空气里有什么？

我们每时每刻都在呼吸，但你有没有想过——吸进来的空气到底是什么？法国科学家拉瓦锡用实验告诉我们：空气不是一种"气体"，而是多种气体的混合物。

第一步：空气的组成

按体积分数计算：

氮气（N₂）：78% —— 最多，性质稳定，用作保护气

氧气（O₂）：21% —— 支持呼吸和燃烧

稀有气体：0.94% —— 氦氖氩氪氙氡，用作电光源

二氧化碳（CO₂）：0.03% —— 光合作用的原料

第二步：氧气的化学性质

氧气是一种化学性质比较活泼的气体，具有助燃性（支持燃烧）和供给呼吸的特性。

【举例】

① 碳 + 氧气 → 点燃 → 二氧化碳（发出白光）

② 硫 + 氧气 → 点燃 → 二氧化硫（发出蓝紫色火焰，有刺激性气味）

③ 铁 + 氧气 → 点燃 → 四氧化三铁（火星四射，生成黑色固体）

④ 磷 + 氧气 → 点燃 → 五氧化二磷（产生大量白烟）

第三步：氧气的实验室制法

三种方法：

① 加热高锰酸钾：2KMnO₄ =△= K₂MnO₄ + MnO₂ + O₂↑

② 过氧化氢分解：2H₂O₂ =(MnO₂催化)= 2H₂O + O₂↑

③ 加热氯酸钾：2KClO₃ =(MnO₂催化△)= 2KCl + 3O₂↑

⚠ 易错警示

易错1："氧气具有可燃性"——❌ 氧气具有助燃性（支持燃烧），自身不可燃。

易错2：铁丝燃烧实验要在集气瓶底部放少量水或细沙——防止高温熔融物溅落炸裂瓶底。

易错3：用排水法收集氧气时，实验结束要先撤导管再熄灭酒精灯——防止水倒吸炸裂试管。

📋 小结

空气：N₂ 78% + O₂ 21% + 稀有气体 + CO₂

O₂性质：助燃性（非可燃性），供给呼吸

O₂检验：带火星的木条伸入瓶中，木条复燃

C组·中考真题

1.【2024·广西中考】下列物质能在氧气中剧烈燃烧，产生火星四射现象的是（ ） A. 蜡烛 B. 红磷 C. 铁丝 D. 硫
【答案】C 【解析】A.蜡烛在氧气中燃烧发出白光，不产生火星；B.红磷在氧气中燃烧产生大量白烟，不产生火星；C.铁丝在氧气中剧烈燃烧，火星四射，生成黑色固体（Fe₃O₄）；D.硫在氧气中燃烧发出蓝紫色火焰，生成有刺激性气味的气体。故选C。
2.【2024·河南中考】空气中含量最多的气体是（ ） A. 氧气 B. 氮气 C. 二氧化碳 D. 稀有气体
【答案】B 【解析】空气按体积分数计算：氮气（N₂）约占78%，氧气（O₂）约占21%，稀有气体约0.94%，二氧化碳约0.03%。因此氮气含量最多。故选B。牢记：氮七八氧二一，零点九四是稀气。
3.【2024·苏州中考】下列关于氧气的说法正确的是（ ） A. 氧气是一种无色无味的气体 B. 氧气可以支持燃烧，但不能燃烧 C. 氧气是空气的主要成分 D. 氧气是一种稀有气体
【答案】B 【解析】A.通常状况下氧气无色无味，但液态氧呈淡蓝色，选项未说明条件，有歧义。B.氧气具有助燃性（支持燃烧），但自身不能燃烧，正确。C.氧气约占空气21%，是主要成分之一，但空气中最主要的是氮气（78%）。D.氧气是常见气体，不属于稀有气体（稀有气体指He、Ne、Ar等）。故选B。

方法总结

方法：氧气性质：支持燃烧（助燃性）、供给呼吸。注意：氧气本身不能燃烧（没有可燃性）。
