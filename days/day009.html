📖 数学 · 不等式（组）

讲（20min）

不等式的基本性质

①加减同一个数，不等号方向不变：a>b → a±c > b±c

②乘除正数，不等号方向不变：a>b, c>0 → ac>bc

③乘除负数，必须变号！ a>b, c<0 → ac < bc

这是最易错的一点！例：a>b，则 −2a < −2b

解一元一次不等式

步骤与解方程相同，但注意：最后一步如果除以负数，不等号要反向。

例：−3x > 9 → x < −3（两边除以−3，变号）

解不等式组

①分别解每个不等式 → ②在数轴上表示解集 → ③取公共部分（交集）

画数轴找交集时：有等号画实心圆●（含端点），无等号画空心圆○（不含端点）。

例：{2x−1>5, 3x+2≤x+10} → {x>3, x≤4} → 交集：3 < x ≤ 4

小结

不等式最核心一条：乘除负数必变号！不等式组=分别解+画数轴+取公共部分。

A组·基础练

1.解不等式2x-1>5
2x-1>5 → 2x>6 → x>3
2.解不等式组{2x-1>5, 3x+2≤x+10}
2x-1>5 → x>3；3x+2≤x+10 → 2x≤8 → x≤4；取交集：3<x≤4
3.若a>b，则-2a___-2b
a>b，两边乘-2(负数要变号)：-2a < -2b
4.不等式2x-4≤0的非负整数解
2x-4≤0 → x≤2，非负整数解：0,1,2

C组·中考真题

1.【2024·北京中考】不等式3x-6>0的解集在数轴上表示为（ ） A. 数轴从2向右 B. 数轴从-2向右 C. 数轴从2向左 D. 数轴从-2向左
【答案】A 【解析】3x-6>0 → 3x>6 → x>2。在数轴上表示为从2向右（空心圈，大于向右）。故选A。
2.【2024·成都中考】不等式组{x+1>0, 2x-4≤0}的整数解有（ ） A. 1个 B. 2个 C. 3个 D. 4个
【答案】B 【解析】x+1>0 → x>-1；2x-4≤0 → 2x≤4 → x≤2。所以解集为-1<x≤2。整数解为0,1,2共3个。选C。 【注意】x>-1不包含-1，x≤2包含2，所以整数解为0,1,2三个。故选C。

方法总结

方法：乘除负数必变号！解集在数轴上表示：实心=包含，空心=不包含。

🔤 英语 · 被动语态

讲（20min）

📖 导入：主动与被动

对比两个句子：
① Students clean the room.（学生们打扫房间/主动语态——强调"谁"打扫）
② The room is cleaned (by students).（房间被打扫/被动语态——强调"房间"怎么样）
什么时候用被动？当我们更关心动作的承受者（即"谁被怎么着了"），而不是动作的执行者时。

第一步：被动语态的核心结构

be + 过去分词（done）

be动词随着时态、人称、数的变化而变化。即：

一般现在被动：am/is/are + done
一般过去被动：was/were + done
一般将来被动：will be + done
现在完成被动：have/has been + done
情态动词被动：can/must/should + be + done

第二步：主动变被动三步法

第1步：把宾语（动作承受者）变成主语（注意主格宾格变化）
第2步：谓语动词变为"be + 过去分词"形式，be动词的时态要和原句保持一致
第3步：原主语变成"by + 宾语"，可以省略（如果不知道或不需要提执行者）

例：Students clean the room.
第1步：The room（宾语变主语）
第2步：is cleaned（一般现在时be=is，clean的过去分词=cleaned）
第3步：by students（原主语变by+宾语）
结果：The room is cleaned by students. ✓

第三步：什么时候不用被动

① 不及物动词(happen/appear/lie等)没有被动：The accident happened.（不能说was happened）
② 表示"拥有"的动词(have/own/belong to)：I have a book.（不能说A book is had）

⚠ 常见错误

忘记加be：The book published last year.(✗) → The book was published last year.(✓)

📋 小结

被动=be+done。be随主语时态变化。主动变被动三步：宾语变主语→be done→by+主语(可省略)。不及物动词无被动。

A组·基础练

1.主动变被动：Students clean the classroom every day.
The classroom is cleaned by students every day.
2.选择：The book ________ (wrote / was written) by Lu Xun.
was written（被动语态）
3.主动变被动：My mother will cook dinner.
Dinner will be cooked by my mother.
4.选择：Tea ________ (grows / is grown) in Fujian.
is grown
5.翻译：这座桥建于2020年。
The bridge was built in 2020.

C组·中考真题

1.【2024·天津中考】The sports meeting ________ (hold) every year in our school.
【答案】is held 【解析】every year表示一般现在时，主语The sports meeting与hold之间是被动关系（运动会"被举办"），所以用一般现在时的被动语态：is/are+done。主语是单数，故填is held。
2.【2024·武汉中考】This kind of machine ________ (make) in China last year.
【答案】was made 【解析】last year表示一般过去时，主语This kind of machine与make之间是被动关系（机器"被制造"），所以用一般过去时的被动语态：was/were+done。主语是单数，故填was made。

方法总结

方法：主动变被动三步：宾语变主语→谓语变be done→主语变by+宾语(可省略)

📖 语文 · 实词理解

讲（20min）

文言实词四大考法

①通假字：说=悦、女=汝、反=返、亡=无
②古今异义：妻子(古=妻子儿女/今=配偶)、牺牲(古=祭祀猪羊/今=献身)
③一词多义：故(原因/所以/旧的/故意)、间(中间/参与/间隔/暗中)
④词类活用：名词→动词、形容词→名词等
解题：语境推断+成语联想。

A组·基础练

1.解释加点词：学而时习之，不亦说乎？（说）
说=悦，愉快（通假字）
2.解释：率妻子邑人来此绝境（妻子/绝境）
妻子=妻子和儿女（古今异义）；绝境=与世隔绝的地方
3.下列加点词意思相同的一组是（ ） A. 温故知新/故人不独亲其亲 B. 跳往助之/惩山北之塞
A（故=旧的/旧的），B（之=代词/助词）

⚡ 物理 · 透镜与成像

讲（20min）

凸透镜成像规律

五种成像情况总结

①u>2f：倒立缩小实像（照相机原理）
②u=2f：倒立等大实像（测焦距）
③f投影仪原理）
④u=f：不成像（平行光）
⑤u放大镜原理）

记忆口诀

一倍焦距分虚实，二倍焦距分大小。实像总是倒立的，虚像总是正立的。物近像远像变大（实像时）。

眼睛与眼镜

眼球的结构：晶状体相当于凸透镜，视网膜相当于光屏。正常眼：远处物体的像成在视网膜上。近视眼：晶状体曲度过大（太凸），远处物体的像成在视网膜前方→用凹透镜矫正（发散光线使像后移到视网膜）。远视眼（老花眼）：晶状体曲度过小（太扁平），近处物体的像成在视网膜后方→用凸透镜矫正（会聚光线使像前移到视网膜）。

A组·基础练

1.判断对错：u>2f时成倒立缩小实像，应用是照相机。
正确。物距大于两倍焦距时成倒立缩小的实像
2.判断对错：uf<u<2f时成正立放大虚像。
错误。f<u<2f时成倒立放大实像（投影仪）。u<f时才成正立放大虚像（放大镜）
3.判断对错：u=2f时成倒立等大的实像，可以用来测焦距。
正确。此时像距v=2f，物体和像等大，f=u/2
4.照相机、投影仪、放大镜分别对应哪种成像情况？
照相机：u>2f（倒立缩小实像）；投影仪：f<u<2f（倒立放大实像）；放大镜：u<f（正立放大虚像）
5.凸透镜对光有什么作用？
会聚作用（能使平行光会聚于焦点）

B组·进阶练

1.近视眼成像在视网膜的什么位置？应该用什么透镜矫正？
成像在视网膜前方，用凹透镜矫正（使光线发散，像后移）
2.远视眼成像在视网膜的什么位置？应该用什么透镜矫正？
成像在视网膜后方，用凸透镜矫正（使光线会聚，像前移）
3.近视眼镜的镜片是凸透镜还是凹透镜？
凹透镜（中间薄边缘厚，对光有发散作用）
4.老花镜的镜片是什么透镜？利用了透镜的什么作用？
凸透镜，利用了凸透镜对光的会聚作用
5.晶状体在眼睛中的作用相当于什么？
相当于凸透镜（对光有会聚作用）

C组·中考真题

1.【2024·成都中考】小明用凸透镜在光屏上得到一个清晰的倒立、缩小的像，则物体距凸透镜的距离u与焦距f的关系是（ ） A. u>2f B. f<u<2f C. u<f D. u=2f
【答案】A 【解析】凸透镜成像规律：①u>2f→倒立缩小的实像（应用：照相机）；②f<u<2f→倒立放大的实像（应用：投影仪）；③u<f→正立放大的虚像（应用：放大镜）。题意是倒立缩小的像，所以u>2f。故选A。
2.【2024·北京中考】近视眼应该佩戴什么透镜？（） A. 凸透镜 B. 凹透镜 C. 平面镜 D. 凸面镜
【答案】B 【解析】近视眼的成因：晶状体太厚（或眼球前后径过长），远处物体的像成在视网膜前方。矫正：佩戴凹透镜，使光线先发散再进入眼睛，像后移落到视网膜上。远视眼（老花眼）则佩戴凸透镜。故选B。

方法总结

方法：口诀：一倍焦距分虚实，二倍焦距分大小。物近像远像变大（实像），物近像近像变小（虚像）。
